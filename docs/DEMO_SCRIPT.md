# Demo Script

A timed demonstration sequence. There are **two** checklists: a mock demo (works
anywhere, all data clearly simulated) and a real-run checklist (requires the
PipeGen toolchain). Use the mock demo to rehearse; the final hackathon
demonstration's live vision portion must use the real PipeGen pipeline.

## The scripted scenario

`phantom_api/demo/scenarios.py` defines a fixed-view **workshop** scene that
loops every 22 seconds:

- Phase 0–12s: two people move **east** (normal) — should not trigger.
- Phase ~2–15s: a person enters the **Restricted Zone** and dwells > threshold.
- Phase ~4–14s: a person moves **west** against the allowed east direction.

Seed regions: `Restricted Zone`, `Work Area`.
Seed rules (prefixed `rule_seed_`): Restricted Zone Entry, a dwell rule, and a
wrong-way rule (see `docs/RULES.md`).

## Mock demo checklist

Simulated indicator: every event shows `is_simulated: true` and is labelled
**SIMULATED**. Never present this as real evidence.

```powershell
# 0:00 - Reset only demo data
scripts\reset-output.ps1

# 0:10 - Start backend (mock auto-starts in demo mode)
scripts\run-backend.ps1

# 0:30 - Start the web UI
scripts\run-web.ps1
```

## Real-run checklist

Only after completing `docs/PIPEGEN_SETUP.md` and verifying the adapter works.
Until then the real path fails transparently.

- [ ] `PHANTOM_DEMO_MODE=false`, executable + export dir set.
- [ ] Startup does **not** fall back to mock.
- [ ] `GET /api/v1/pipeline/preflight` reports ready.
- [ ] Start a `real` run; confirm `adapter_kind` and `is_simulated` are not mock.
- [ ] Capture the **Pipeline IR graph screenshot** from PipeGen.
- [ ] Capture the **TensorRT speed report** generated by PipeGen.
- [ ] Record the exact **model and precision** used.
- [ ] Demonstrate an **actionable output** (JSON export and/or MQTT alert).
- [ ] Update the **Evidence** registry to `captured`, then explicitly `verify`.
- [ ] Confirm no fabricated metrics appear anywhere in the UI.

## What is simulated

In the mock demo, **all** observations, tracks, coordinates and resulting events
are generated by the deterministic scripted scenario. None of it is real
inference, and no model, precision, FPS, latency, or GPU telemetry is produced.
The UI labels this explicitly.
