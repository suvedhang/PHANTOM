# Evidence Checklist

Required submission artifacts for the hackathon. Statuses are tracked in the app
under **Evidence** and via `GET /api/v1/evidence/status`.

Statuses: `missing` → `pending` → `captured` → `verified` (or `invalid`).
Setting a path marks `captured`; **only an explicit verify marks `verified`**.
A configured path is never treated as verification.

## Required artifacts

| Artifact | Type | Source | Required |
| --- | --- | --- | --- |
| PipeGen Pipeline IR node graph screenshot | `pipeline_ir_graph` | PipeGen | Yes |
| TensorRT speed report generated by PipeGen | `tensorrt_speed_report` | PipeGen | Yes |
| Live pipeline run on supported NVIDIA hardware | `live_run` | PipeGen | Yes |
| Actionable output demonstrated (JSON/MQTT/alert) | `actionable_output` | PHANTOM | Yes |
| Repository link and PipeGen export folder | `repo_and_export` | Both | Yes |
| Exact model and precision used in the live run | `model_precision_note` | PipeGen | No |

## How to complete each item

1. **Pipeline IR graph** — capture the node graph **from PipeGen itself**. Do not
   fabricate or redraw it.
2. **TensorRT speed report** — export the report PipeGen generates. Do not
   present mock timing as a TensorRT report.
3. **Live run** — run the real pipeline on the NVIDIA host and record the run.
4. **Actionable output** — export events as JSON (or publish over MQTT) and keep
   the artifact under `output/exports/`.
5. **Repo and export** — record the repository link and the PipeGen export
   folder containing the above.
6. **Model/precision note** — record the exact model and precision. Optional.

## Recording and verifying

```powershell
# Record the exported artifact path (marks it captured)
Invoke-RestMethod -Method Put `
  -Uri http://127.0.0.1:8000/api/v1/evidence/model_precision_note `
  -ContentType application/json `
  -Body '{"path":"output/exports/run.json","notes":"fp16 YOLO model"}'

# Explicitly verify (after confirming the file is real)
Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:8000/api/v1/evidence/model_precision_note/verify
```

`required_verified` reaches `required_total` and `complete` becomes `true` only
when every required artifact is explicitly verified.

## What must never be submitted as evidence

- Mock/SIMULATED observations or event streams.
- A mock TensorRT report or a redrawn pipeline graph.
- Any latency, FPS, or GPU figure not produced by the real toolchain.
